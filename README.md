# Ankit Kumar — Machine Learning Engineering Portfolio

Personal portfolio highlighting production GenAI, RAG, agentic workflows,
physics-informed ML, statistical modeling, and data engineering work.

Live site: [ankitkr8540.github.io/portfolio](https://ankitkr8540.github.io/portfolio/)

## Featured work

- Mitra — bounded agentic RAG and university decision support
- Physics-constrained thermal prediction for embedded inference
- PyLinguist — cross-lingual Python translation and evaluation
- Enterprise financial KPI forecasting
- Earlier ML research, product applications, and developer tooling

## Technology

React, React Bootstrap, GitHub Pages, and EmailJS.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

Create a production build:

```bash
npm run build
```

Publish the build to GitHub Pages:

```bash
npm run deploy
```
